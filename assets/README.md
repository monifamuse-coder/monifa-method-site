# /assets — Muse demo clips for /get-the-system

Drop your MP4s in here with these exact filenames and they appear on the sales
page automatically. No code changes needed.

| File | Where it shows | Suggested content |
|---|---|---|
| `muse-generate-pricing.mp4` | Sales page, "See It Happen", left | Screen recording: answer Muse's pricing questions → hit Generate → the filled-in worksheet appears |
| `muse-generate-landing.mp4`  | Sales page, "See It Happen", right | Screen recording: hit Generate on Pillar 05 → landing page copy appears → click Download PDF |

Optional but recommended — a still frame shown before play:
`muse-generate-pricing.jpg` and `muse-generate-landing.jpg`

Guidance:
- 20–40 seconds each. Long enough to show the payoff, short enough to watch.
- Under ~15MB each (Vercel serves these fine; anything much bigger gets slow on mobile).
- Silent is fine — most people watch with sound off. Burn in a caption if you need one.
- End the clip ON the finished artefact. That frame is the entire argument.

If a file is missing, the page still works — the browser just shows the poster
or a download link. Nothing breaks.
